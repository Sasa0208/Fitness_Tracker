# Fitness_Tracker
Tracker Kebugaran Jasmani adalah aplikasi web yang dirancang sebagai produk akhir dari proyek STEM Kelompok 8. Aplikasi ini memungkinkan peserta didik untuk mencatat hasil tes kebugaran fisik secara terstruktur, menganalisis data antar sesi latihan, dan mendapatkan evaluasi kondisional berbasis logika komputasional.
