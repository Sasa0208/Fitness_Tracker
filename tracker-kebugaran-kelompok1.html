Komponen Computational Thinking

1
Dekomposisi
Latihan dibagi jadi bagian kecil — push-up, sit-up, lari, plank — masing-masing diukur terpisah agar mudah dianalisis.
2
Abstraksi
Performa fisik disederhanakan jadi angka: jumlah repetisi dan durasi — mudah dibandingkan antar sesi dan antar peserta.
3
Pengenalan Pola
Data antar sesi dibandingkan untuk melihat tren peningkatan atau penurunan — dasar untuk menyesuaikan intensitas latihan.
4
Conditional Logic (Logika Kondisional)
Jika repetisi < target → tingkatkan intensitas. Jika sudah melampaui target → naikkan target atau tambah jenis latihan baru.
5
Algoritma Rutinitas
Urutan logis: Tes awal → Catat data → Analisis → Evaluasi hasil → Sesuaikan rutinitas → Ulangi siklus.
